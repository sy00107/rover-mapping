# 경사면 안의 작은 초록 구간 표시 보정

사용자 요청에 따라 경사면 사이에 짧게 끼어 있는 평지 색상을 주변 경사면 색상으로 연결한다.
`slope_display.py`에서 지형 격자의 원본 경사/높이를 읽어 별도의 표시 마스크를 계산하고,
`surface_colors.py`의 기존 색칠 경로에서 지면 정점에만 적용한다. 기본 동작으로 활성화했다.

## 임계값

- 초록 구간 폭 최대 15cm. 가로·세로·대각 방향의 실제 미터 간격으로 검사한다.
- 구간 양쪽에 각각 15cm 이상의 원래 경사 셀이 이어져 있어야 한다.
- 반경 20cm 안의 알려진 지면에서 원래 경사 셀 비율 65% 이상.
- 주변 경사 셀의 높이 평면 적합 각도 7도 이상, RMS 잔차 1.5cm 이내.
- 후보 셀 높이가 해당 평면과 2cm 이내로 연결돼야 한다.

모든 판정은 보정 전 경사 셀을 사용한다. 새로 칠한 셀이 연쇄 확장의 근거가 되지 않는다.
미관측 지면, 장애물, 넓은 평지 및 높이 단차에는 적용하지 않는다. 경사·높이·분류·비용
원자료는 바꾸지 않는다. 실제 짧은 평지가 위 조건을 충족하면 색상으로 구별하지 못할 수 있다.

## 실제 기록과 검증

- 12:36 Map 5: 5cm 격자 8셀 보정.
- 12:40 Map 2/29/40/52: 각각 23/14/6/2셀 보정.
- 경사각 기반 가정 통합본도 새 표시 규칙으로 재생성했다. 배치/메시 생성 방법은 유지했다.
- 짧은 초록 섬, 넓은 실제 평지, 경사 시작/끝, 높이 단차, 미관측 영역,
  장애물 및 원자료 불변 회귀를 포함한 관련 테스트 49개 통과.
- 변경 Python pyflakes 및 git diff --check 통과.

`surface_point_colors(..., smooth_slope_colors=False)`로 원래 임계값 표시를 비교할 수 있다.
`apply_surface_colors` 결과의 `slope_display_correction`에 사용 임계값과 보정 셀 수가 남는다.
