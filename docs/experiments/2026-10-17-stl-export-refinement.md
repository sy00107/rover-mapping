# STL 내보내기 전용 표면 보정

매핑·원본 depth·TSDF·지형 층의 처리는 유지하고, STL로 내보내는 사본에만 별도 보정을 적용한다.

```bash
bash tools/export_mapping_stl.sh \
  outputs/handheld_mapping/merged/all_valid_sessions_2m_consensus \
  --backend orb_offline \
  --output outputs/handheld_mapping/exports/my_stl_export
```

출력 폴더는 새 경로여야 한다. 기존 결과가 있으면 덮어쓰지 않고 실패한다. 다른 기록은 RUN과 새 output 경로를 지정한다. 매핑 중인 기록 대신 저장·지형 생성이 끝난 결과를 사용한다.

## 보정 범위

- 원본 표면과 동일한 입력에서 면적이 사실상 0인 면·중복 면을 정리해 `map_raw.stl`을 만든다. 작은 독립 물체·장애물은 통째로 지우지 않는다.
- 지면·장애물 내부에 법선 방향 Taubin 보정 16회를 적용한다. 총 이동 한계는 지면 8mm, 장애물 15mm다. 경사면을 수평으로 만들지 않는다.
- 열린 경계·분류 경계·45도 이상 모서리·4cm보다 긴 메시 edge·미분류 정점은 고정한다. 지면과 장애물을 서로 섞지 않으며 기존 연결을 늘리지 않는다.
- 분류가 바뀌거나 삼각형이 뒤집히거나 크게 무너지면 관련 정점을 되돌린다. 국소 복원이 해결되지 않으면 평활화 전체를 원래 정점으로 되돌린다.
- 지면의 닫힌 내부 구멍만 최대 지름 8cm·40변·국소 평면 잔차 4mm에서 채운다. 경사면에서는 해당 경사면을 따라 채운다. 외곽·큰 구멍·미분류 공간은 그대로 둔다.
- 새 면의 꼭짓점·변 중점·중심이 모두 같은 지형 결과에서 지면으로 확인돼야 한다. 빈 곳을 관측 근거 없이 전역으로 채우거나 수밀한 솔리드를 만들지 않는다.
- 채움 면이 기존 메시 edge를 중복으로 사용해 비다양체 edge를 만들면 해당 구멍 채움을 거부한다. 실제 지도에서 이 예외 3건을 확인하고 회귀 테스트를 추가했다.

기존 화면 보정은 여전히 지름 5cm·20변의 기본값을 쓴다. STL 보정 설정을 화면·매핑 기본값에 적용하지 않는다.

## 결과와 검증

- `map_raw.stl`: 같은 좌표계의 보정 전 비교본.
- `map_refined.stl`: STL 전용 보정본. 좌표 수치는 미터이며 STL 자체에는 단위·색·지도 좌표계가 저장되지 않는다.
- `map_refined.ply`: 지면·장애물·미분류 색이 남은 비교용 사본.
- `inferred_faces.npy`: 출력 삼각형 순서에 대응하는 bool mask. True인 면은 작은 구멍을 보완한 추정 면이다.
- `quality.json`: 이동량·채움 수·열린 경계 수·입력 해시·보정 한계와 검증 결과.

두 STL 모두 이진 삼각형 좌표가 내보낸 float32 좌표와 일치하는지 검사한다. 원본 PLY와 지형 summary/npz의 전후 해시도 확인한다.

합성 테스트는 기울어진 면의 잡음 감소·경사 보존·이동 상한, 미분류/모서리/외곽 보존, 뒤집힘·붕괴 복원, 화면 기본값보다 큰 지면 구멍의 제한적 채움, 관측이 없는 내부의 채움 거부, 원본 보존 및 STL 실제 읽기를 검사한다.

시각적 평활화는 지형 정확도나 충돌 안전성 보증이 아니다. 열린 큰 틈·별도 조각은 남을 수 있고 자기 교차 검사는 별도다. 이 결과만으로 Nav2 입력·위치 추정·실기 주행 검증이 완료되지 않는다. 경사 테스트 촬영을 누적 통합에 새로 넣지 않는다.

## 기존 평지 통합 지도에 적용한 결과

`outputs/handheld_mapping/exports/all_valid_sessions_2m_consensus_stl_refined_v2`에 보정 전·후 STL과 색상 PLY를 저장했다. 271,086개 정점을 보정했으며 실제 최대 이동은 지면 5.68mm, 장애물 6.17mm였다. 지면 구멍 1,044개에 추정 면 3,827개를 추가하고, 기존 면과 충돌하는 채움 3건은 거부했다. 출력 비다양체 edge는 0개이며 분류 변화도 0개다. 원본 해시가 유지됐고 보정 전·후 이진 STL 좌표를 확인했다. 열린 경계는 128,371개에서 122,456개로 감소했지만 수밀 모델은 아니다.
