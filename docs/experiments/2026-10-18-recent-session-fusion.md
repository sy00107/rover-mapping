촬영 전체에 고정 SE(3)를 적용하는 기존 다중 영상 등록은 별도 검증 영상의 재투영 검사를 통과하지 못했다. 대신 각 영상의 RootSIFT 특징점을 기준 영상의 미터 단위 깊이와 대응시키고, 해당 영상의 카메라 위치를 PnP로 직접 추정했다. 기준 특징점 검색에는 CLAHE와 최대 4m 깊이를 사용했다.

영상별 특징점 ID로 사전에 1/3을 검증용으로 분리한다. 나머지 특징점만 RANSAC/LM에 사용한다. 후보 기준 영상은 학습 특징점 인라이어 수로 선택하며, 검증 잔차로 후보를 고르지 않는다. 검증 재투영 오차 중앙값 3px/90백분위 6px 이내, 별도 원본 깊이 비교 중앙값 6cm/90백분위 15cm 미만, 인접 영상 간 이동/회전 연속성을 통과한 영상만 사용했다. 이는 영상 내 특징점 검증이며 촬영 단위 독립 영상 검증이나 실측 정확도 인증은 아니다.

80개 원본 깊이 영상에 기존 공간/다중 시점 필터를 적용하고, 2m 범위/1cm 복셀 TSDF로 다시 적분했다. 통합 PLY는 71,790 정점/128,816 삼각형이다. 지형 분류도 동일한 깊이로 생성했고 경사 지면은 핑크색이다. 입력 파일 SHA256와 깊이 파일 SHA256는 merge.json에 기록했다. 원본 메타데이터와 복구본의 전체 raw가 원본과 동일함을 source_verification.json으로 확인했다.
