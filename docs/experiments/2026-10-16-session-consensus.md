## IMU 중력 기준이 없는 촬영의 정렬

`SessionImages(..., allow_visual_frame=True)`는 원본 SLAM camera 좌표로 영상·metric depth의 PnP 정렬을 수행할 수 있다. 임의의 IMU 중력 JSON을 만들지 않는다. 기준 촬영은 기존의 정지 IMU 중력 frame을 유지한다. 보고서 `source_frame=slam`, `source_to_reference`와 map ID 및 입력 hash를 기록하고, 병합기는 그 좌표 계약에 따라 pose를 변환한다. 원래 중력 좌표를 가진 보고서와 이전 세 촬영의 변환 계약은 유지한다.

모양이 비슷한 장면을 찾는 VLAD 검색은 후보 영상 검색에만 쓴다. 실제 채택은 양방향 RootSIFT·metric depth PnP·여러 시점의 재투영 최적화와 분리한 held-out source 영상 검사로 결정한다. 중력 기준이 없다는 이유로 raw camera frame에 부적절한 z-up 회전 제한을 적용하지 않는다.

추가된 `172951/map246`은 train source19영상, held-out 오차 중앙값1.330px·p90 3.046px였다. `map488`은 train source19영상, held-out 중앙값0.605px·p90 1.435px였다. held-out 영상은 consensus 선택과 최적화에 사용하지 않았다. 원본의 다른 map 조각은 서로의 좌표를 알고 있다고 가정하지 않고 각각 검증했다.

## 촬영 간 충돌 필터

새 `--cross-session-filter`는 원본을 바꾸지 않는2단계 처리다.

1. 각 촬영의 기존 공간/다중 시점 필터를 통과한 depth로 공통3D voxel의 표면 및 관측된 빈 공간 근거를 만든다.
2. 원본 depth를 공통 TSDF에 넣기 전, 다른 촬영의 근거와 대조해 충돌 관측을 제외한다.

실제 결과의 voxel은5cm다. 표면은 같은 촬영의2개 이상 frame에서, 빈 공간은3개 이상 frame에서 확인해야 한다. 빈 공간은 카메라 ray 위에서 실측 표면보다 광축 깊이 기준 최소10cm 앞의 위치만 표시한다. voxel 양자화와 작은 정렬/깊이 오차를 보호하기 위해 표면 근거는 인접1셀까지 적용한다.

현재 촬영 자신의 표면 관측은 독립적인 확인으로 쓰지 않는다. 다른 촬영이 그 위치를 빈 공간으로 보았고, 다른 어느 촬영도 근처 표면을 지지하지 않을 때만 제외한다. 다른 촬영의 물체 뒤에 가려졌거나 아예 관측되지 않은 위치는 충돌로 판정하지 않고 보존한다. 같은 촬영의 여러 map 조각은 한 표를 공유한다. map 개수만큼 독립 촬영이 늘었다고 계산하지 않는다.

이것은 보수적인 관측 충돌 검사다. 반복되는 모든 오측정, 움직인 물체, pose drift를 완전히 구분하지 못하며, 다른 촬영에서 확인되지 않은 관측을 정상으로 인증하지도 않는다.

## 실제 생성 결과

- 촬영4개, 검증한 map 조각5개.
- 사용한 keyframe1,595개:252+333+233+65+712. 오래된 촬영의 원래 누락112개 때문에 결과 status는 `partial`이다.
- 기존 필터 이후 비교한 깊이 관측216,830,564개 중 충돌228,727개(약0.1055%) 제외.
- 다른 촬영의 인접 표면 근거가 있는 관측213,669,252개, 추가 확인 없이 보존한 관측2,932,585개. 이 비율은 지도 정확도/센서 동기화 정확도가 아니다.
- 최종 정점531,451개·삼각형937,743개. 작은 표면 조각 정리와 기존 viewer 표시 평활화/작은 지면 구멍 보완을 적용한다.
- 사용한 원본 depth와 입력 index/calibration/pose/gravity hash, 기존 입력·기본 결과58파일의 hash가 모두 동일했다.
- 처리 중간의 필터된 depth cache는 결과 생성 후 정리했고 원본을 삭제하지 않았다.

검사 보고서, 제외 사유, 비교 그림, 표시 검증은 `outputs/handheld_mapping/reviews/all_sessions_merge/`에 저장했다. 이전 두/세 촬영 통합본도 그대로 남겨뒀다.

## 검증

별도 IMU 파일 없이 검증된 camera 좌표를 정렬·융합하는 경로, 복수 map 조각의 단일 촬영 표 공유, 실제 depth ray의 가림 보호, 자기 촬영의 중복 확인 금지, 불안정한 단일 frame 빈 공간 근거 거부, 다른 촬영의 표면 지지 및 미관측 보존, grid 메모리 상한을 검사했다.
